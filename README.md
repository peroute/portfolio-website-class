# Portfolio Website

A simple starter portfolio page, built with plain HTML and CSS.

## 📁 Structure

```
portfolio-website-class/
├── index.html          # Main page
├── css/
│   └── style.css        # Basic stylesheet
├── images/               # Place photos here
├── files/                # Place downloadable files here (e.g. CV.pdf)
└── README.md
```

## ✏️ Customizing

- Edit the text directly in `index.html`.
- Basic styling lives in `css/style.css`.

## 🚀 Running locally

Just open `index.html` in your browser.
